# اتاق راهبری پاکار

داشبورد تک‌صفحه‌ای فارسی برای دسترسی به Q3، امور روزانه، میزیتو و امور مالی، همراه با گزارش وضعیت و بانک تصمیم‌ها.

## معماری

- رابط ثابت قابل انتشار روی GitHub Pages؛ فایل `index.html` خروجی آماده است.
- Supabase مستقل با شناسه `ihcpohnoduvwxdpnjcze`؛ ورود ایمیل/رمز و ذخیره آنلاین در Postgres.
- جدول `workspace_members` فهرست اعضای مجاز را نگه می‌دارد. ثبت‌نام به‌تنهایی دسترسی به داده‌ها نمی‌دهد.
- جدول `records` چالش‌ها و تصمیم‌های مشترک تیم را نگه می‌دارد؛ RLS دسترسی را کنترل می‌کند.
- نقش `viewer` فقط مشاهده و نقش‌های `editor` و `owner` ایجاد و ویرایش دارند.
- حذف از رابط نرم است: `deletedAt` مقدار می‌گیرد و رکورد در دیتابیس باقی می‌ماند.
- تغییر هم‌زمان یک یادداشت با کنترل `updatedAt` تشخیص داده می‌شود.
- شیت‌ها و میزیتو فقط لینک هستند؛ هیچ خواندن یا نوشتن خودکاری روی آن‌ها انجام نمی‌شود.

## ساخت

```sh
npm ci
npm run build
```

منبع در `src/` و ساختار دیتابیس در `database/schema.sql` است. نسخه پکیج‌ها و lockfile ثابت هستند. کد مرورگر فقط کلید publishable دارد؛ کلید service_role در کد وجود ندارد.

## انتشار و تنظیم ورود

1. در GitHub Pages، انتشار از شاخه `main` و پوشه ریشه را فعال کنید.
2. نشانی نهایی سایت را در Supabase، Authentication → URL Configuration، به‌عنوان Site URL و Redirect URL مجاز ثبت کنید.
3. ثبت‌نام و تأیید ایمیل اولین مدیر را از صفحه ورود انجام دهید. فهرست اعضای مجاز در دیتابیس مدیریت می‌شود؛ پنهان کردن دکمه‌ها جایگزین RLS نیست.
4. ورود، ثبت چالش، ثبت تصمیم، ویرایش، خروج و بارگذاری مجدد را روی سایت واقعی بررسی کنید.

## وضعیت فعلی این نسخه

ساخت تولیدی و بررسی TypeScript انجام شده است. آزمون تراکنشی ایجاد، ویرایش، حذف نرم و جلوگیری از دسترسی فرد غیرعضو انجام شده و تمام داده‌های آزمایشی rollback شده‌اند. بررسی امنیتی Supabase بدون هشدار بود.

تا پیش از ساخته‌شدن مخزن، فعال‌کردن GitHub Pages و تنظیم URL تأیید ایمیل، این نسخه «منتشرشده و آماده استفاده» محسوب نمی‌شود.
